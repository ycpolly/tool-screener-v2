## 一、第 1 層：個股狀態標籤（Header Badges）

位於卡片首行股票代號、名稱與現價周圍的核心狀態警示：

| 標籤 / 樣式 | 觸發判定條件 | 視覺表現 | 業務意涵與風控提示 |
| :--- | :--- | :--- | :--- |
| **`[處置]`** | `stock.isDisposed === true` | 低飽和暗磚紅字（`text-rise`，#c0392b） | **主管機關公告處置股票**（俗稱「關禁閉」）。每 5 分鐘或 20 分鐘人工撮合一盤，並預收款券。流動性大幅驟降、撮合延遲，具高度流動性風險。 |
| **價格紅底塊狀** | `stock.isLimitUp === true` 或 `changePct >= 9.5%` | 紅底白字（`bg-rise text-white rounded font-bold`） | **強勢漲停**或逼近漲停鎖死。當日買盤極度強勁。 |
| **價格綠底塊狀** | `stock.isLimitDown === true` 或 `changePct <= -9.5%` | 綠底白字（`bg-fall text-white rounded font-bold`） | **弱勢跌停**或逼近跌停鎖死。賣壓沉重無人接盤。 |

## 四、第 3 層：籌碼透視區塊（Chips Section）

由後端爬取當日前 15 大券商買賣超資料，並結合歷史回測時光機累積之真實籌碼歷史計算：

### 1. 籌碼集中度（Concentration）
- **格式**：`籌碼集中度 1D +18.4% · 3D +7.2% · 5D -2.1%`
- **計算公式**：`（前 15 大買超券商買超總張數 - 前 15 大賣超券商賣超總張數）÷ 該期間總成交張數 × 100%`
- **視覺規範**：
  - **正值（`> 0`）**：呈現上漲磚紅字（`text-rise font-bold`，如 `+18.4%`），代表籌碼正集中流入少數特定主力手中，具集聚拉抬動能。
  - **負值（`≤ 0`）**：呈現一般中性文字色（`text-base-content`，如 `-2.1%`），代表籌碼正從大戶手中發散給多數散戶接盤，籌碼渙散。

### 2. 短沖避雷佔比與大戶分點名單（Day Traders Info）
- **格式**：`短沖佔 35.2% (凱基-台北 · 台灣摩根士丹利 · 美林)`
- **監控分點**：系統追蹤市場著名隔日沖與極短線大戶券商分點（包括：`凱基-台北`、`美林`、`台灣摩根士丹利`、`新加坡商瑞銀`、`美商高盛`、`富邦-建國`、`元大-土城永寧` 等）。
- **風控提示**：
  - 當短沖佔比過高（如 `> 20%` 或 `> 30%`）時，強烈警示**隔日早盤極易面臨短沖大戶高檔倒貨破壞均線的賣壓**，切忌盲目追高。

## 五、槽位 B：篩選評估理由與 12 項指標通關診斷

### 1. 外部預覽摘要標籤
- **符合策略時**：顯示 `符合「模式名稱」選股條件`（全部模式時為 `符合策略：多頭回測 · 洗盤起漲`）。
- **未符合時**：外層直接聚合致命淘汰條件，如 `2 項未達標：未站穩 5MA · 成交量不足`，無需點開即可秒判淘汰原因。

### 2. 點擊展開之 12 項指標通關診斷清單（✓ 通過 / ✗ 未達標）

點擊槽位 B 可就地向下展開 12 項關鍵量化條件診斷清單，無 Modal 遮擋且支援文字反藍複製：

| 指標診斷項目 | 通過判定標準（✓） | 未達標判定標準（✗） | 業務代表意義 |
| :--- | :--- | :--- | :--- |
| **5MA 均線** | 現價 `price >= ma5` | 現價 `price < ma5` | 是否站上最短週期攻擊生命線 5MA。 |
| **10MA 均線** | 現價 `price >= ma10` | 現價 `price < ma10` | 是否站穩雙週防守線 10MA。 |
| **20MA 月線** | 現價 `price >= ma20` 且月線斜率向上（今日 ma20 > 昨日 ma20） | 現價破月線，或月線下彎扣高走平 | 確保波段多頭趨勢成立，避開下彎月線的助跌破線股。 |
| **60MA 季線** | 現價 `price >= ma60` | 現價破季線 | 生命線保護，確認大週期多頭防線。 |
| **三線糾結** | `(Max(5,10,20) - Min(5,10,20)) / Min <= 閾值`（預設 3.5%，精選 2%） | 價差大於閾值，均線過度發散 | 均線極致壓縮凝聚，代表市場持有成本趨於一致，即將蓄勢發動。 |
| **成交量能** | 當日成交量達到門檻（預設 500/1000 張，精選 2000 張） | 成交量未達門檻 | 流動性保護，確保進出順暢，杜絕冷門僵屍股。 |
| **量能倍數** | 今日成交量相較 5 日均量放量（如 `volume >= 1.5 * vMa5`） | 量能萎縮無動能 | 攻擊確認，必須帶量表態方能突破盤整。 |
| **昨日量縮** | 昨日成交量小於昨日 5 日均量（`prevVolume < prevVMa5`） | 昨日帶量長黑或異常爆量 | 窒息量確認，洗盤末期浮額沉澱訊號。 |
| **實體紅 K** | `(close - open) / prevClose >= 門檻`（預設 2.5%，精選 3.5%） | 實體棒過短或收黑 K | 當日主力實質作多表態，非假突破的上影線或墓碑線。 |
| **避開長黑** | 近 3 日內無跌幅 `> 4%` 之長黑破線棒 | 近 3 日出現長黑重挫 | 避開主力倒貨出逃或技術線型遭重力破壞的弱勢股。 |
| **KD 動能** | K 值處於攻擊區（`k > 50`）且黃金交叉（`k >= d`） | K 值弱勢超賣或死叉下探 | 動能指標轉強發動點。 |
| **避雷檢核** | 近期無外資／主力／投信連續 3 日賣超（0050 豁免） | 遭三大法人大額連續提款 | 嚴格籌碼避雷，防範倒貨風險。 |

## 六、底層指標看板：均線、KD、走勢與關卡

卡片底層視覺儀表板的各項指標規範：

1. **均線數值與乖離率（Bias %）**：
   - 即時展示 `5MA`、`10MA`、`20MA` 均線數值及其對應之乖離率百分比。
   - **計算公式**：
     $$\text{乖離率 (\%)} = \frac{\text{現價} - \text{均線價格}}{\text{均線價格}} \times 100$$
   - **正負乖離色彩邏輯（站上 vs 跌破）**：
     - 🔴 **紅色（`text-rise`，正乖離）**：現價 > 均線（如 `(+2.4%)`），代表站穩均線之上，屬多方/強勢格局，依台股慣例標為紅色。
     - 🟢 **綠色（`text-fall`，負乖離）**：現價 < 均線（如 `(-1.8%)`），代表跌破均線（如 `(-1.8%)`），屬弱勢/回檔修正格局，標為綠色。
     - ⚪ **中性色（`text-base-content/75`）**：現價剛好等於均線（`0.0%`）。
   - **均線層級的視覺權重差異（為何有些 MA 是紅的、有些不是？）**：
     - **5MA（極短線攻擊生命線）**：🔴 正值紅 / 🟢 負值綠。屬於策略核心考核指標，一眼辨識股價是否強勢站穩 5 日線。
     - **10MA（雙週線，輔助防守線）**：⚪ **固定中性文字色（`text-base-content/80`）**。刻意不帶紅綠色，避免卡片同時出現過多紅綠交錯產生視覺雜訊（Noise），保留純淨數值對照。
     - **20MA（月線，波段多空分水嶺）**：🔴 正值紅 / 🟢 負值綠。屬於波段核心生命線，快速掌握波段是否處於多頭保護或面臨月線下彎乖離。
2. **均量（Volume Moving Average）**：
   - `5MV`（5 日均量）、`10MV`（10 日均量），以千張/張數格式化展示。
3. **KD 動能狀態徽章（KD Status）**：
   - **`黃金交叉`**：K 值由下往上穿越 D 值。
   - **`高檔鈍化`**：K 值持續大於 80。
   - **`低檔超賣`**：K 值持續小於 20。
   - **`死亡交叉`**：K 值由上往下跌破 D 值。
   - **`中性整理`**：KD 指標處於 20~80 區間震盪。
4. **走勢 Sparkline 折線圖**：
   - 提取真實近 10 日收盤價繪製微型走勢圖，獨立展示波段趨勢。
5. **天花板關卡價與預期純利（槽位 A：Ceiling & Net Profit）**：
   - **槽位 A 視覺展示**：位於標籤區下方之獨立導流按鈕列，點擊觸發 `RiskModal`。
   - **第一道最近天花板（Nearest Resistance）**：
     - 自動從「5日/10日/20日高點」、「5/10/20/60MA 均線反壓」與「整數關卡價」中，選出最靠近現價的第一道阻力。
   - **扣除稅費預期純利（Net Profit %）**：
     - 公式：$$\text{預期純利率 (\%)} = \frac{\text{天花板關卡價} - \text{現價}}{\text{現價}} \times 100 - 0.58\%$$
     - 預先扣除 **0.58%** 標準交易摩擦成本（買賣手續費與證券交易稅），純利為正時以磚紅字高亮（`text-rise`）。
   - **空間與風控全貌 Modal（RiskModal）**：
     - **上方壓力天花板列表**：由近到遠羅列所有壓力關卡與扣除稅費後純利率，最近第一關標註醒目徽章。若創歷史新高無上方壓力，則自動 Fallback 為漲停價天花板 (+10%)。
     - **下方防守支撐點列表**：由近到遠羅列 5/10/20 日低點與均線支撐，並計算跌至各支撐點之預估虧損幅度 %。
     - **預估風報比（Reward / Risk Ratio）**：以第一道天花板預期純利對比最近防守支撐虧損（保底 5%），評估進場勝率空間與風險報酬比。
