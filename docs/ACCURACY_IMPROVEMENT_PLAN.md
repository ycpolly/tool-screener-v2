# 五大模式準確度提升規劃書

> **建立日期**：2026-10-04
> **目的**：系統性記錄當前選股精準度的缺口，以及對應的資料補充方案。
> **問題背景**：2026-10-01 多頭回測共出現 12 檔訊號，其中 4551 智伸科表現最佳，
>   但當天無法從 12 檔中事先辨識出來。本文件分析原因並提出可量化的改善路徑。
> **閱讀對象**：前端 AI（Gemini）負責 UI 呈現；後端 AI（Claude）負責資料爬取與計算。

---

## 一、核心問題定義

### 現狀
篩選引擎是純二元判斷（通過 / 不通過），通過的股票之間沒有排名。  
結果：12 檔多頭回測訊號，使用者必須自行從中挑選，準確度高度依賴個人盤感。

### 目標
對每個通過篩選的股票額外計算「綜合評分」，讓最有波段潛力的股票排在最前面。

---

## 二、四種關鍵缺失（依重要性排序）

### 缺失 A：月營收動能（最重要）

**問題**：4551 智伸科在多頭格局中表現最佳，背後幾乎一定有月營收年增率的支撐。
技術面完全相同的兩支股票，一支月營收年增 60%、一支月營收衰退 5%，波段空間天壤之別。

**目前狀態**：完全缺乏基本面資料。選股完全是純技術 + 籌碼，沒有基本面確認。

**影響的模式**：所有五個模式均受益，尤其是「底部蓄勢」和「多頭回測」。

---

### 缺失 B：相對大盤強弱（最快實作）

**問題**：12 檔通過多頭回測的股票裡，有些在市場回測期間跌比大盤多，有些跌比大盤少。
跌比大盤少的股票代表「下方有人在撐」，是主力在保護籌碼的訊號。

**目前狀態**：有個股 sparkline（10 日收盤價），也有大盤加權/櫃買指數資料，
但尚未計算「個股相對大盤的超額報酬」。

**計算方式**：
  - 上市股：relStrength5d = 個股近 5 日漲跌幅 - TAIEX 近 5 日漲跌幅
  - 上櫃股：relStrength5d = 個股近 5 日漲跌幅 - OTC 近 5 日漲跌幅
  - 正值 = 強於大盤（漲更多或跌更少），負值 = 弱於大盤

**影響的模式**：多頭回測、洗盤起漲、底部蓄勢（尋找在整理期間仍相對強勢的股票）。

---

### 缺失 C：股本大小（流通籌碼量）

**問題**：主力要拉動一支股本 5 億的股票，所需資金是股本 50 億股票的 1/10。
同樣的法人買超金額，在小股本股票上能製造更大的漲幅空間。

**目前狀態**：完全缺乏股本資料。目前以「成交量 ≥ 1000 張」作為流動性門檻，
但未區分股本大小的波段空間潛力差異。

**影響的模式**：所有模式均受益。小股本（≤ 30 億）的波段標的往往比大股本更容易拉動 5%~15%。

---

### 缺失 D：籌碼集中度的連續趨勢

**問題**：目前顯示「今日籌碼集中度」是單點數值，但更有意義的是趨勢方向：
  - 連續 3 天籌碼集中度上升 → 主力持續建倉，波段可信度高
  - 今日突然集中 → 可能只是當沖行為，隔天可能反向
  - 連續上升後今日集中度最高 → 主力已完成建倉，即將發動

**目前狀態**：chipsHistory 近 10 日快照已存在 stock-pool.json，
但前後端尚未計算集中度的 3 日趨勢（上升/持平/下降）。

**影響的模式**：底部蓄勢（確認主力確實在建倉）、洗盤起漲（確認洗盤是主力行為而非散戶出逃）。

## 三、六種資料鑑別方案

### 方案 1：月營收年增率（YoY Revenue Growth）

| 項目 | 說明 |
| :--- | :--- |
| **資料來源** | 公開資訊觀測站 MOPS（isin.twse.com.tw）每月 10 日前強制公告 |
| **爬蟲 URL** | https://mops.twse.com.tw/mops/web/ajax_t05st10_ifrs（POST 請求，帶月份參數）|
| **更新頻率** | 每月一次（月初抓前一個月的營收），可搭配現有 GitHub Actions |
| **預期欄位** | evenueYoY: 62.5（%，正值為年增，負值為年減） |
| **篩選建議** | 可選條件：月營收年增率 > 20% 才納入推薦；> 50% 視為強力催化劑 |
| **鑑別效益** | ⭐⭐⭐⭐⭐ 最高 |
| **實作難度** | 中（MOPS HTML 解析，POST 請求，需處理上市/上櫃分開） |
| **負責方** | 後端 AI |

**預期 JSON 格式**：
`json
{
  "code": "4551",
  "revenueYoY": 62.5,
  "revenueLatestMonth": "2026-09",
  "revenueMoM": 8.3
}
`

### 方案 2：相對大盤強弱（Relative Strength）

| 項目 | 說明 |
| :--- | :--- |
| **資料來源** | 已有：個股 sparkline（10 日收盤）+ market.taiex / market.otc 指數資料 |
| **計算方式** | 上市股：elStrength5d = stockChg5d - taiexChg5d；上櫃股對 OTC 指數 |
| **需要新增** | market.taiex 需新增 chg5d（5 日漲跌幅）欄位；market.otc 同步新增 |
| **更新頻率** | 每次爬蟲更新時即時計算，不需要額外 HTTP 請求 |
| **預期欄位** | elStrength5d: +3.2（%，正值 = 強於大盤，負值 = 弱於大盤）|
| **UI 顯示** | StockCard 上以 +/- 色系顯示；排序時由高到低 = 最強勢優先 |
| **驗證依據** | MarketBanner 需同步顯示 TAIEX / OTC 的 5 日漲跌幅基準值，讓使用者交叉確認 |
| **鑑別效益** | ⭐⭐⭐⭐ 高 |
| **實作難度** | 低（不需要新爬蟲，純計算） |
| **負責方** | 後端 AI（計算 + 欄位）、前端 AI（UI 顯示 + MarketBanner 補基準值）|

**預期 JSON 格式**：
`json
{
  "code": "4551",
  "relStrength5d": 3.2
}
`
`json
"market": {
  "taiex": {
    "chg5d": -1.8
  },
  "otc": {
    "chg5d": -2.1
  }
}
`

### 方案 3：股本大小（Paid-in Capital）

| 項目 | 說明 |
| :--- | :--- |
| **資料來源** | TWSE/TPEx 基本資料 API（一次抓完，非每日更新）|
| **更新頻率** | 每週更新一次即可（股本不常變動） |
| **預期欄位** | paidInCapital: 5.2（億元，浮點數）|
| **篩選建議** | 可選條件：股本 ≤ 30 億視為「小股本加成」；> 100 億視為大型股（波段空間較小）|
| **鑑別效益** | ⭐⭐⭐⭐ 高（小股本股票波段空間通常是大股本的 2~5 倍）|
| **實作難度** | 低（靜態資料，格式穩定）|
| **負責方** | 後端 AI |

**預期 JSON 格式**：
`json
{
  "code": "4551",
  "paidInCapital": 5.2
}
`

### 方案 4：籌碼集中度連續趨勢（Chip Concentration Trend）

| 項目 | 說明 |
| :--- | :--- |
| **資料來源** | 已有：chipsHistory 近 10 日快照 |
| **計算方式** | 取最近 3 日的籌碼集中度，判斷趨勢方向（上升 / 持平 / 下降）|
| **預期欄位** | chipsTrend3d: "UP"（"UP" / "FLAT" / "DOWN"）、chipsScore: 3（連續上升天數）|
| **篩選建議** | 底部蓄勢、洗盤起漲模式可加入「籌碼連續 3 日集中趨勢向上」作為可選加分條件 |
| **鑑別效益** | ⭐⭐⭐ 中高 |
| **實作難度** | 低（不需要新資料，在 screener.js 或 writer.py 計算）|
| **負責方** | 後端 AI（計算）、前端 AI（UI 顯示趨勢箭頭）|

**預期 JSON 格式**：
`json
{
  "code": "4551",
  "chipsTrend3d": "UP",
  "chipsScore": 3
}
`

### 方案 6：大股東持股比例（Major Shareholder Ownership %）

| 項目 | 說明 | 
| :--- | :--- |

| **建議** | 優先實作方案 1~4，此方案列為長期規劃 |

## 五、前端顯示規格（供 Gemini 參考）

### 相對大盤強弱（方案 2）
- StockCard 顯示：相對強弱 +3.2%（綠色）或 相對強弱 -1.5%（紅色）
- MarketBanner 補充：顯示 TAIEX 5日 -1.8% / OTC 5日 -2.1% 作為比對基準
- 排序欄位新增：可選「相對強弱」排序，高到低

### 月營收年增率（方案 1）
- StockCard 顯示：營收年增 +62.5%（正 = 綠色，負 = 紅色）
- 旁邊標示資料月份：(09月)
- 篩選器新增：可選過濾「月營收年增率 ≥ X%」

### 股本（方案 3）
- StockCard 顯示：股本 5.2 億
- 小股本（≤ 20億）加上醒目標籤以示波段空間較大

### 籌碼集中趨勢（方案 4）
- StockCard 現有籌碼集中度旁邊加趨勢箭頭：↑↑↑ / ↑ / → / ↓
- 連續 3 日以上上升 → 顯示橘色/金色加強提示
