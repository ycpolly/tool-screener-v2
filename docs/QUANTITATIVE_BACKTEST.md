## 一、量化回測方法論（Methodology）

### 1. 拒絕「漲停回推」，杜絕倖存者偏差（Survivorship Bias）
一般散戶容易從「今日漲停股」回推篩選條件，這在統計上只能測得「查全率（Recall，抓漏）」，無法測得「精確率（Precision，勝率）」。若策略選出 100 檔股票中僅包含 8 檔漲停、其餘 92 檔下跌，盲目進場依然會招致重創。

本專案全面採用**前向持有期回測（Forward Backtesting）**：
- 在歷史第 $T$ 日收盤時，由選股引擎客觀產出各模式命中名單。
- 以 $T$ 日收盤價作為進場成本 $P_0$。
- 嚴格追蹤後續 $T+1 \sim T+10$ 日（一至兩週）的真實價格路徑。

### 2. 評估指標定義
- **5 日內觸及 +5% 機會率**：持有期間內，盤中最高價曾達到 $P_0 \times 1.05$ 的比率（驗證是否有給予充裕的獲利了結機會）。
- **平均最高漲幅 (MFE, Maximum Favorable Excursion)**：持有期間最高點相對於進場點的平均拉開空間。
- **平均最深跌幅 (MAE, Maximum Adverse Excursion)**：持有期間最低點相對於進場點的平均拉回幅度。
- **先跌破 -3% 停損率先觸發率**：在盤中摸到 +5% 之前，先跌破進場價 -3.0% 的機率（驗證進場後的破線風險）。
- **持有期勝率 (Win Rate)**：$T+3$ 與 $T+5$ 收盤價高於進場價 $P_0$ 的比率。

## 三、實戰代表個股案例覆盤 (Case Studies)

### 案例 1：創意 (3443) ── 洗盤起漲 (`WASHOUT_IGNITION`)
- **選出日期**：`2026-09-10`
- **選出進場價**：`6225`
- **5 日內最高漲幅**：**+14.9%**（於進場後第 6 天衝至高點 7150）
- **5 日內最深拉回**：`-6.0%`
- **觸及 +5% 目標**：**是（進場後第 2 天即達成）**
- **T+5 收盤表現**：`6500`（**+4.4%**）
- **模式驗證點**：
  符合「洗盤起漲」之順勢均線架構。月線向上且前日量縮洗盤，當日放量表態後迅速拉開空間，具備極高的平均最高獲利率（+6.3%）。

### 案例 2：威剛 (3260) ── 底部蓄勢 (`BOTTOM_CONSOLIDATION`)
- **選出日期**：`2026-09-09`
- **選出進場價**：`414.5`
- **5 日內最高漲幅**：`+-0.1%`（隔日最高僅 414）
- **5 日內最深拉回**：**-7.1%**（低點持續破底至 385）
- **觸及 +5% 目標**：**否**
- **T+5 收盤表現**：`399.5`（**-3.6%**）
- **模式驗證點**：
  印證了「底部蓄勢」在盤整震盪市場中的特性。三線糾結壓縮股尚未正式表態，容易因大盤回檔演變為向下破底發散。回測數據顯示該模式有 **33.3%** 會先跌破 -3%，若無堅守「跌破盤整下緣立即停損」之紀律，容易陷入被動套牢。

## 四、各模式發酵週期與實戰操作指引

```
發酵天數短 ────────────────────────────────────────── 發酵天數長
1 ~ 3 天        2 ~ 5 天        3 ~ 7 天        5 ~ 15 天
[動能攻擊]      [跌深反轉]      [多頭回測]      [底部蓄勢]
               [洗盤起漲]
```

### 1. 動能攻擊 (`MOMENTUM_BREAKOUT`) ── 短跑突破型
- **發酵週期**：**1 ~ 3 天**
- **操作心法**：既然是帶量長紅突破，進場後 3 天內必須見到紅 K 續強。若進場後軟掉或跌破突破點，通常代表主力假突破或隔日沖倒貨。目前回測先跌破 -3% 機率高達 50%，需嚴守快速停損。

### 2. 洗盤起漲 (`WASHOUT_IGNITION`) ── 波段接力型
- **發酵週期**：**2 ~ 5 天**
- **操作心法**：月線向上多頭格局，昨日量縮拉回洗盤，今日放量轉強。主力洗過浮額後拉抬，通常 3 ~ 5 天內能順暢拉開 5% ~ 10% 空間，為當前盤勢的進攻主力之一。

### 3. 多頭回測 (`TREND_PULLBACK`) ── 防守反擊型
- **發酵週期**：**3 ~ 7 天**
- **操作心法**：多頭趨勢量縮回測 5MA / 10MA 支撐，測試量縮不破後重啟攻勢。本模式 5 日內摸到 +5% 機會率高達 **50.6%**，平均拉開幅達 **+7.1%**，是目前全市場勝率與期望值最高的策略。

### 4. 底部蓄勢 (`BOTTOM_CONSOLIDATION`) ── 長跑潛伏型
- **發酵週期**：**5 ~ 15 天**（約 1 ~ 3 週）
- **操作心法**：三線極致壓縮，籌碼沉澱但方向尚未表態。持有需要 1 ~ 2 週耐心；**下檔必須嚴格以糾結區下緣（約 -3%）為停損防線**，不破抱大底起漲波（+15% ~ +30%），一破立刻果斷撤退。

### 5. 跌深反轉 (`BOTTOM_REVERSAL`) ── 急行軍型
- **發酵週期**：**2 ~ 5 天**
- **操作心法**：負乖離過大後的低檔第一根強彈，目標是向月線靠攏；前 2 ~ 3 天速度極快，但一碰到月線通常有解套賣壓，屬於「快進快出、絕不戀棧」的超短線搶反彈模式。

## 五、後續策略優化建議

1. **底部蓄勢增加「籌碼防護網」**：
   引入法人賣超避雷開關（`excludeSell3D`），剔除外資投信連續出貨的假整理標的。
2. **動能攻擊增加「爆量上影線過濾」**：
   提高長上影線限制門檻，濾除盤中被主力隔日沖倒貨的虛胖標的。
3. **定期回測排程化**：
   每週末可透過 `npm run backtest` 定期檢視過去一個月策略命中率之變動，動態掌握策略在不同市場多空燈號（SAFE / CAUTION / DANGER）下的實效。

### 第二批：新增篩選邏輯（需修改 screener.js）

目標檔案：
- `src/engine/screener.js`（新增 2 段評估邏輯）
- `src/constants/screener-modes.js`（新增對應參數開關）

#### 2-A 底部蓄勢 — 新增籌碼確認條件 (`requireAnyBuy`)

**問題**：T+5 ≥+5% 率為 0%，根本原因是混入了法人出貨的假整理，需確認至少一個法人方向正確。

`screener-modes.js` — 在 `BOTTOM_CONSOLIDATION.defaultParams` 新增：

```js
requireAnyBuy: true,   // 需屬於 SitcaBuy 或 ForeignBuy 或 MajorBuy 任一分類
```

`screener.js` — 在 `excludeSell3D` 區塊之後插入（維持現有檢查順序）：

```js
// 籌碼確認 (requireAnyBuy: 需屬於至少一個法人買超分類)
if (params.requireAnyBuy) {
  const cats = stock.categories || []
  const hasBuySupport = cats.some(c =>
    ['SitcaBuy', 'SitcaBuy3D', 'SitcaBuy5D',
     'ForeignBuy', 'ForeignBuy1D', 'ForeignBuy3D',
     'MajorBuy', 'MajorBuy1D', 'MajorBuy3D'].includes(c)
  )
  if (!hasBuySupport) {
    return fail('無法人買超支撐（外資/主力/投信均無買進）')
  }
}
```

預期：底部蓄勢勝率大幅提升，訊號數可能略減（在 1-C 放寬後仍有足夠候選池）。

#### 2-B 動能攻擊 — 新增量能倍數參數 (`minVolExpansionRatio`)

**問題**：現在只要量 > 5MA 量即可，微量突破也能通過，隔日沖風險高。改為要求量能達 5MA 量的 1.5 倍。

`screener-modes.js` — 在 `MOMENTUM_BREAKOUT.defaultParams` 新增：

```js
minVolExpansionRatio: 1.5,  // 當日量需 >= 5MA量 × 1.5
```

`screener.js` — 找到 `checkVolExpansion` 區塊（約第 542 行），改為：

```js
// 修改前
if (params.checkVolExpansion && vMa5 > 0 && volume <= vMa5) {
  return fail(strings.volExpansionFailed || '未達帶量攻擊標準 (成交量 ≤ 5日量均)')
}

// 修改後（支援 minVolExpansionRatio，其他模式無此參數時自動 fallback 至 1.0）
if (params.checkVolExpansion && vMa5 > 0) {
  const ratio = typeof params.minVolExpansionRatio === 'number'
    ? params.minVolExpansionRatio : 1.0
  if (volume < vMa5 * ratio) {
    return fail(strings.volExpansionFailed ||
      `未達帶量攻擊標準 (成交量 < 5日量均 × ${ratio})`)
  }
}
```

> 注意：其他模式使用 `checkVolExpansion` 時若未設定 `minVolExpansionRatio`，fallback 到 1.0，維持原有行為，不影響其他模式。

預期：動能攻擊訊號數再減（更嚴），先跌 -3% 率目標降至 35% 以下。
