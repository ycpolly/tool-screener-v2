## 一、資料時間與狀態判定邏輯

系統頂部狀態列會根據當前時間與即時行情狀態，自動判定所屬盤面階段並標註中文前綴：

| 狀態前綴 | 時段判定 (台灣時間 CST) | 資料來源依據 | 點擊「更新」按鈕行為 | 畫面時間戳記範例 |
| :--- | :--- | :--- | :--- | :--- |
| **盤前** | 週一至週五 00:00 ~ 08:59 | 前一交易日盤後爬蟲資料庫 | 攔截請求，彈出提示：<br>「尚未開盤（09:00 正式開盤），維持盤後選股結果」 | `盤前 26/09/04 週五 22:34` |
| **盤中** | 週一至週五 09:00 ~ 13:30 | GCP 行情 API 即時報價 | 連線 GCP 代理取得最新現價、均線與 KD，即時重算篩選結果 | `盤中 26/09/07 週一 10:15` |
| **收盤** | 週一至週五 13:30 ~ 17:00 | 盤中收盤價快照（未出盤後爬蟲前） | 若有即時報價顯示 13:30 收盤行情；若無則顯示盤後資料庫 | `收盤 26/09/07 週一 13:30` |
| **盤後** | 每日 17:00 ~ 23:59、週末全天 | GitHub Actions 每日產出之盤後資料庫 | 週末點擊會攔截請求，彈出提示：<br>「週末休市，維持週五盤後選股結果」 | `盤後 26/09/04 週五 22:34` |

> **資料安全與防護機制**：非即時開盤時段（盤前與休市）一律嚴格保護底層資料庫，禁止 0 成交量或未撮合試撮價沖銷既有選股名單。

## 二、雲端資料庫排程（GitHub Actions 兩波流）

部署於雲端的自動化排程機器人於每個台股交易日（週一至週五）分兩波抓取官方公開資訊並部署：

| 排程波次 | 執行時間 (台灣時間 CST) | 抓取內容與更新範圍 |
| :--- | :--- | :--- |
| **第一波** | **16:38** | 抓取盤後三大法人、15 組官方熱門與量能排行、0050/0051 成分股、處置股名單及 Yahoo 歷史 K 線，產出 5 大選股模式初步名單。 |
| **第二波** | **18:42** | 券商分點進出明細出爐，完整更新個股 1D / 3D / 5D 籌碼集中度與主力短沖避雷標籤。 |

- **手動觸發**：若遇特殊情況需立即於雲端重新爬取，可至 GitHub 儲存庫的 **Actions** 頁面選擇 `Update Stock Pool` 工作流，點擊 **Run workflow** 即可手動啟動。

## 三、18 大選股池來源標籤速查

每日自動納入監控的 18 大核心資料來源，個股卡片次行標籤可直接點擊外開對應之官方即時排行榜：

### 1. 熱門與量能排行
- **量大**（`Top100` / `VolumeTop`）：當日成交量前 100 大個股（富邦 DJ 上市 `zg_BE_0_1` / 上櫃 `zg_BE_1_1`）。
- **值大**（`ValueTop`）：當日成交金額前 100 大個股，法人與大主力資金集結指標（富邦 DJ 上市 `ZG_CD` / 上櫃 `zg_CD_1`）。
- **值增**（`ValueGrowth`）：成交金額增幅排行，今日動能爆發性倍增之標的（富邦 DJ 上市 `zg_CB_0_0` / 上櫃 `zg_CB_1_0`）。
- **週轉**（`TurnoverRate`）：當日週轉率排行，代表市場資金極度活躍、籌碼劇烈換手（富邦 DJ 上市 `ZG_BD` / 上櫃 `zg_BD_1_0`）。

### 2. 法人與主力買超排行
- **外資買 / 外資1D / 外資3D**（`ForeignBuy` / `ForeignBuy1D` / `ForeignBuy3D`）：外資單日買超排行或連續 3 日累計買超標的（富邦 DJ `zg_D` 系列）。
- **投信買 / 投信3D / 投信5D**（`SitcaBuy` / `SitcaBuy3D` / `SitcaBuy5D`）：本土投信單日積極進場或連 3 日、連 5 日波段認養鎖碼股（富邦 DJ `zg_DD` 系列）。
- **主力買 / 主力1D / 主力3D**（`MajorBuy` / `MajorBuy1D` / `MajorBuy3D`）：特定買超大戶單日集中掃貨或連 3 日鎖碼標的（富邦 DJ `zg_F` 系列）。

### 3. 指數成分股與防護機制
- **0050**：元大台灣 50 成分股，市值前 50 大權值龍頭（享風控豁免保護，連 3 賣不強制剔除以避免錯殺）。
- **0051**：元大中型 100 成分股，中型成長股核心池。

### 4. 賣超避雷警示標籤（紅字警示）
- **外資連賣**（`ForeignSell3D`）：外資連續 3 日賣超。
- **主力連賣**（`MajorSell3D`）：特定主力連續 3 日賣超。
- **投信連賣**（`SitcaSell3D`）：投信連續 3 日調節賣超。
